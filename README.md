## 🚀 Project Features & Technologies

- Developed the app’s core modules *(authentication, splash, and home screens)* using **Kotlin** with the **MVVM** architecture and **Hilt** for dependency injection.
- Integrated **Firebase services**: Authentication, Firestore database, Storage, and basic Cloud Functions *(Node.js - authentication only)*.
- Connected backend APIs with **Retrofit** and used **Postman** for API testing and documentation.
- Efficiently managed asynchronous tasks using **Kotlin Coroutines** and **Flows**.
- Built the UI with both **XML** and **Jetpack Compose**, following **Material Design 3** guidelines.
